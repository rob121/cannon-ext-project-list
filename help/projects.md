# Projects

Open Projects in the Cannon admin. A project name opens the view. Edit Project opens the form.

- Name, description, and resources needed are required.
- Complete By is optional. Leave it blank to hide the date on the public page.
- The public heading and introduction are edited from Page Text.
- Active must be checked, and status must be Open, for the project to appear on the site.
- Pending, in progress, and completed projects stay in the admin list only.
- The view lists every adoption, newest first. The project list shows how many adoptions each project has.

Search matches the project name, description, resources needed, complete-by date, and any adopter's name, email, phone, note, or proposed date. The status menu filters the list.

Deleting a project also deletes its adoption records.
